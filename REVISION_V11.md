# Revisión UX v11

Esta versión conserva la lógica pedagógica y de pagos de v10 y mejora únicamente experiencia y navegación.

## Cambios principales
- Navegación inferior persistente: Inicio, Atlas, Academia y Ajustes.
- Inicio con progreso visible de Matemáticas.
- Academia deja de depender de Configuración como ruta de navegación.
- Configuración reorganizada por Experiencia, Cuenta y Solo adultos.
- Retorno consistente entre Inicio, Atlas y Academia.
- Jerarquía cromática simplificada: cian para navegación, amarillo para acciones, violeta para NOVA y verde para éxito.
- Mejor espaciado inferior para móvil/tablet y áreas táctiles más previsibles.
- No se modificaron Mercado Pago, Supabase, NOVA, misiones, rutas ni estructura de progreso.
