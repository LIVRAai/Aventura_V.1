# Revisión de producto · V15

## Problema corregido

La aplicación usaba **Atlas** y **Academia** como categorías principales. Esos nombres funcionan como narrativa infantil, pero no explican con claridad a una familia qué habilidad académica se está reforzando.

## Criterio aplicado

Se separaron dos capas:

- **Capa pedagógica:** Matemáticas → División → Comprensión / Procedimiento / Propiedades / Aplicación.
- **Capa narrativa:** Atlas Animal, mundos, criaturas, misiones y NOVA.

## Cambios principales

1. Matemáticas presenta ahora el tema **División** de forma explícita.
2. Las dos etapas principales se llaman **Comprender la división** y **Resolver divisiones paso a paso**.
3. Atlas Animal aparece como nombre de la aventura, no como objetivo académico.
4. El entrenamiento de NOVA agrupa las prácticas en:
   - Aprender el procedimiento.
   - Entender las propiedades.
   - Aplicar lo aprendido.
5. Se eliminó del flujo infantil el reporte técnico/analítico de habilidades para evitar redundancia.
6. Se agregó **Perfil → Progreso de aprendizaje** para el adulto.
7. El reporte familiar distingue recorrido de contenido de dominio observado.
8. Se corrigió la terminología visible de “ruta” cuando en realidad se trata de una habilidad o práctica.
9. Se mantuvieron intactas las mecánicas, datos de progreso, tutor NOVA, cuenta y pagos.

## Responsive

El nuevo reporte familiar tiene composición de dos columnas en PC/tablet amplia y una sola columna en móvil. Los estados pasan debajo de la habilidad en pantallas estrechas para evitar cortes o texto comprimido.
